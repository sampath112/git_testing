# Your Year with ChatGPT – Archetype Card

A premium, glassmorphic React card component built with Tailwind CSS, following forensic design specifications.

## Features

✓ Multi-layer gradient background with radial light blooms
✓ Glassmorphism with backdrop blur
✓ Grain overlay for tactile feel
✓ Soft shadows and rounded geometry
✓ Floating animation
✓ Smooth hover interactions
✓ Pastel color system
✓ Opacity-based text hierarchy

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view it in your browser.

## Build

```bash
npm run build
```

## Design Philosophy

This card intentionally uses:
- Soft gradients (not flat)
- Rounded geometry (no sharp corners)
- Pastel depth (low saturation)
- Ambient motion (slow, gentle)
- Glassmorphism (frosted acrylic effect)
- Grain texture (print-like quality)

Premium but friendly. Technical but soft.
